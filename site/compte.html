Aucun abonnement rattaché

Vous êtes bien connecté, mais nous ne trouvons pas d'abonnement lié à ce compte. C'est presque toujours parce que l'adresse de votre compte Discord n'est pas celle utilisée lors du paiement.

Vous pouvez le rattacher vous-même en deux minutes, depuis le serveur Discord ZiProject! :

  1. Tapez /activer email: suivi de l'adresse utilisée pour votre paiement.
  2. Vous recevez un code à 6 chiffres sur cette adresse, valable 15 minutes.
  3. Tapez /activer code: suivi de ce code. Votre rôle est posé et votre abonnement apparaît ici.

Le code prouve que la boîte mail est bien la vôtre. C'est pour cette raison qu'une simple adresse ne suffit jamais à ouvrir un accès.
